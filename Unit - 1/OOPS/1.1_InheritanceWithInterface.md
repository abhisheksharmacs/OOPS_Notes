```java
interface Animal {
    void sound();
}

class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {

        Dog d = new Dog();
        d.sound();
    }
}
```

### How it works

* `Animal` is an **interface**.
* It contains a method declaration `sound()`.
* `Dog` is a **class** that implements the `Animal` interface.
* Since `Dog` implements `Animal`, it must provide the definition of `sound()`.
* An object of `Dog` can then call `sound()`.

**Output:**

```text
Dog barks
```


### Inheritance with Interface in Java

Interfaces and inheritance are related, but they work a little differently from classes.

### 1. Interface Inheriting Another Interface

An interface can inherit another interface using the `extends` keyword.

```java
interface Animal {
    void eat();
}

interface Dog extends Animal {
    void bark();
}
```

Here:

* `Dog` inherits `eat()` from `Animal`
* Any class implementing `Dog` must provide definitions for both `eat()` and `bark()`

```java
class PetDog implements Dog {

    public void eat() {
        System.out.println("Dog is eating");
    }

    public void bark() {
        System.out.println("Dog is barking");
    }
}
```

---

### 2. Multiple Inheritance with Interfaces

A major advantage of interfaces is that an interface can inherit multiple interfaces.

```java
interface Camera {
    void clickPhoto();
}

interface MusicPlayer {
    void playMusic();
}

interface SmartDevice extends Camera, MusicPlayer {
    void connectInternet();
}
```

A class implementing `SmartDevice` must implement all methods.

```java
class Smartphone implements SmartDevice {

    public void clickPhoto() {
        System.out.println("Photo clicked");
    }

    public void playMusic() {
        System.out.println("Music playing");
    }

    public void connectInternet() {
        System.out.println("Connected to Internet");
    }
}
```

---

### 3. Class Inheriting a Class and Implementing an Interface

A class can extend one class and implement one or more interfaces.

```java
class Vehicle {
    void start() {
        System.out.println("Vehicle Started");
    }
}

interface Electric {
    void charge();
}

class ElectricCar extends Vehicle implements Electric {

    public void charge() {
        System.out.println("Charging...");
    }
}
```

Usage:

```java
ElectricCar car = new ElectricCar();

car.start();
car.charge();
```

Output:

```
Vehicle Started
Charging...
```

---

### Important Points

| Classes                                                  | Interfaces                                  |
| -------------------------------------------------------- | ------------------------------------------- |
| Use`extends`                                           | Use`extends` between interfaces           |
| A class can extend only one class                        | An interface can extend multiple interfaces |
| A class uses`implements` to inherit interface behavior | Interfaces contain method contracts         |

### Interview Question

**Can an interface extend a class?**

❌ No

```java
interface A extends MyClass { }   // Error
```

An interface can extend only other interfaces.

**Can a class implement multiple interfaces?**

✅ Yes

```java
class Test implements A, B, C {
    // implement methods
}
```

This is how Java achieves **multiple inheritance of behavior** without allowing multiple inheritance of classes.
